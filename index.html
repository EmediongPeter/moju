Download Moju for Android

Free test build · Android 6.0 or newer

  1. Tap Download. If Chrome says the file might be harmful, tap Download anyway.
  2. Open the downloaded file. If Android asks, allow installs from this source, then go back.
  3. Tap Install. If Play Protect asks, tap More details, then Install anyway.
  4. Open Moju, choose Stream to my PC, and allow the camera and microphone.

Why the warnings? Moju is in testing and isn't on the Play Store yet, so Android asks you to confirm. It goes away once Moju is published there.
